# Material Icons Outlined

Source: the owner's `material-icons` 1.13.14 distribution, `iconfont/material-icons-outlined.woff`
and `_data/codepoints.json`. Upstream: https://github.com/marella/material-icons.
License: Apache License 2.0; complete text in `LICENSE.txt`.

The WOFF container was converted to TrueType with fontTools for Qt font loading.
The original glyph designs and codepoints are retained. No font conversion tool
or network access is required at runtime. The supplied map also names glyphs
absent from this specific outlined font; the provider checks actual font coverage
and rejects unavailable icon names rather than drawing missing-glyph boxes.
