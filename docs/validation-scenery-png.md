# PNG character creation removed

PNG character creation and all generated character/template experiments have
been removed. The generated atlas assembly and single-character prototype are
not shipped. Earlier PNG creator validation results do not describe an available
feature.

The library contains 454 original entries. Creators expose SVG artwork only.
Ordinary PNG import, embedded project assets, tint and transparent export remain
supported. Cached PNG thumbnails for the SVG content library remain intact.
