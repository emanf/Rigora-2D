## Implementation and resolved findings

Cameras are separately owned scene records, sharing the existing transform
contract without entering reusable Object artwork, mesh/bone collections or
render draw order. New user scenes receive Main Camera; asset-building scratch
scenes explicitly omit it so placing characters does not add or switch cameras.
Old camera-less documents retain their original canvas projection.

Camera transforms describe the output frame in world space. Rendering applies
its inverse to evaluated display geometry; canonical deformation/physics inputs
remain unchanged. The main workspace keeps geometry editable outside frames.
The optional output preview shares original artwork and evaluates no second
simulation. Static background SVGs are cached by their actual settings rather
than rebuilt on every transform sample. Imported images are project assets.

The first pointer check found that the shared drag preview command omitted the
new camera collection from its commit fields. Including cameras fixed the
actual release/Undo path. Timeline track discovery, row filtering and channel
drops now include cameras in Main Scene while keeping them out of Object Editor.
Camera cuts use exclusive stepped `camera.active` keys authored together by the
Switch Camera command. Camera Reset affects transforms only, preserving active
cuts and avoiding artwork opacity/visibility tracks. Dimensions and colors,
including alpha, are validated before entering history.
